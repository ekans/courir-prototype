# courir-prototype

Prototype du site de Courir Fonsegrives, club de course à pied de Quint-Fonsegrives.

En ligne : https://ekans.github.io/courir-prototype/

## Contenu

- Une seule page, `index.html`, sans fichier local à côté.
- Images et PDF chargés depuis [courir-fonsegrives.fr](https://courir-fonsegrives.fr).

## Voir en local

Ouvrir `index.html` dans un navigateur.

## Publier

GitHub Pages sert la racine de `main`.
Chaque push sur `main` relance la publication (environ une minute).
